This index connects the tool stack to its purpose and owning reference.
**Standard** links define agreed requirements. **Guide** and **Code** links
describe current implementation; their presence here does not make a tool
mandatory in every application.

## Capture, ingestion, and storage

| Tool or service | Purpose and boundary | Reference |
| --- | --- | --- |
| Defuddle | Article-content extraction from the active tab DOM before Clipper review. | [Guide: Capture and review](/developer/web-clipper/capture) |
| fflate | Clipper review ZIP generation for Article XML and Manifest files. | [Guide: Clipper bundles](/developer/web-clipper/bundles) |

| OpenAI Embeddings API | Vector generation through Core's direct HTTP adapter. | [Guide: Semantic processing](/developer/core/ingestion/semantics) |

The OpenAI and object-storage integrations use direct HTTP adapters. Their
implementation references identify the actual owners; they do not imply an SDK
dependency. [Shared packages](/developer/packages) covers the internal workspace
packages that support these capabilities.

Passing an executable check does not replace the owning standard.

## Exceptions

[Standards exceptions](/standards/exceptions) defines the approval process.
[Exception records](/standards/exception-records) distinguishes active permission
from closed historical allowances. Implementing agents cannot approve their own
exceptions or expand an existing approval.
